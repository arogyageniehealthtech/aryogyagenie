## Hemoglobin & Red Blood Cell Reference
Normal Adult Hemoglobin: Adult Males 13.8 - 17.2 g/dL, Adult Females 12.1 - 15.1 g/dL. Hemoglobin levels <12.0 g/dL indicate anemia requiring etiology workup (iron deficiency, B12 deficiency, or chronic blood loss).

## Leukocyte (WBC) & Platelet Standards
Normal White Blood Cell (WBC) count is 4,500 to 11,000 /mcL. Elevated WBC count (>11,000 /mcL, leukocytosis) strongly suggests acute bacterial infection, severe systemic inflammation, or physiological stress response. Normal platelet count is 150,000 to 450,000 /mcL.
