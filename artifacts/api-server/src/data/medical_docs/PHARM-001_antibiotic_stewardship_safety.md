# Antibiotic Stewardship & Pharmacological Safety Rules
Document ID: PHARM-001
Source: CDC Core Elements of Antibiotic Stewardship & WHO Safety Standards
Publisher: World Health Organization & CDC
Document Type: pharmacology_protocol
Version: 4.1

## Stewardship Rules
Systemic antibiotics (e.g. Amoxicillin, Azithromycin, Ciprofloxacin) should be prescribed exclusively for confirmed or highly suspected bacterial infections. Patients must complete full courses as directed to prevent emerging antimicrobial resistance. Monitor renal function and confirm allergy history before prescribing beta-lactams.
