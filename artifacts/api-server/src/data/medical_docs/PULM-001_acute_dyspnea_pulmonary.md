# Acute Dyspnea & Respiratory Assessment Protocol

Source: Global Initiative for Asthma (GINA) & ATS Clinical Guidelines
Publisher: American Thoracic Society
Document Type: clinical_guideline
Version: 2025.2

## Respiratory Evaluation Criteria
Acute shortness of breath accompanied by wheezing, persistent intercostal retractions, low pulse oximetry oxygen saturation (<95% SpO2), or cyanosis warrants immediate emergency pulmonary assessment for acute asthma exacerbation, COPD flare, acute pneumonia, or pulmonary embolism.
